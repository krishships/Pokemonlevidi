Reads dialogue and menus from the screen so a text-only model can follow the story without a picture.
Vision tokens are what runs you into 429. Every turn he already gets the screen decoded to text — a 30x20 grid, what is around him, which edges have exits, and the dialogue box read out. That text is always sent. A picture is optional and expensive: about 1,500 of the 8,000 free tokens per minute, so 0 (text only) is the default and gives roughly three times as many turns. Set 1 only if you want him to see sprites and colour.
Free API plans have rate limits. The page also throttles itself to stay under the free token limit; raise this if you still see 429.
